Exclusive detection of a short whitelist of MLIP calculators. Returns (True, model_obj) when calc is recognized and the expected attribute exists (non-None). Otherwise returns (False, None).

Rules:

  • If mace.calculators.mace is available, treat any instance of MACECalculator (including user subclasses) as supported and prefer attributes ‘mace_model’ then ‘model’. If none present, return the wrapper instance itself.

  • For other supported wrappers (fairchem, sevenn, orb_models, mattersim, graph_pes, metatomic), match by the exact module substring provided and return the first non-None attribute in the listed order.

  • No other calculators will be reported as supported.

Main algorithm for canonical evolutionary Monte Carlo (EMC).

Parameters:

  • name (str) – Name of the target system.

  • calculation_dir (str) – Path of the calculation directory.

  • calculation_script (str) – The name of the Python script for calculating the fitness of each configuration. The script must be inside calculation_dir.

  • input_pop (list of ase.Atoms objects) – Input population for the EMC run.

  • fix_indices (list of ints, default None) – A list of atom indices that should be immutable and fixed in positions throughout the EMC run. Nothing is fixed by default.

  • trim_generation (int, default 100) – To trim database (with backup) every N steps. The database file would be too large and adding new data would be too slow without trimming.

  • md_generation (int, default 10) – To perform molecular dynamics every N steps.

  • exchange_generation (int, defatul 1) – To perform replica exchange every N steps.

  • crossover_rate (float, default 0.) – The rate of performing crossover operations.

  • intraswap_rate (float, default 0.) – The rate of performing intraswap operations in the catalyst slab.

  • metal_element_pool (list of strs, default None) – The list of target metal elements (including vacancy ‘X’) that should be mutable during the EMC run.

  • nonmetal_element_pool (list of strs, default None) – The list of target non-metal elements (including vacancy ‘X’) that should be mutable during the EMC run.

  • mutable_metal_indices (list of ints, default None) – The list of metal atom (or ‘X’ which represents vacancy) indices that are allowed to mutate during the EMC run. Default None means all metal indices are mutable.

  • mutable_nonmetal_indices (list of ints, default None) – The list of non-metal (or ‘X’ which represents vacancy) indices that are allowed to mutate during the EMC run. Default None means all non-metal indices are mutable.

  • raw_score_cutoff (float, default -10000.) – The fitness score for candidates that are should not be considered in the sampling. This could be structures that are unphysical / failed to relax by the calculator.

  • temperature_key (str, default 'temperature') – Keyword for the temperature stored in each configuration.

  • replica_key (str, default 'replica') – Keyword for the replica number stored in each configuration.

  • acceptance_key (str, default 'accepted') – Keyword for indicating being accepted or not in each configuration

  • gpu_devices (list of ints, default None) – The list of GPU devices to use. Default is to use a single GPU/CPU device.

  • procs_per_device (int, default 1) – The number of processes to run in parallel on each GPU/CPU device. Defaul is to run in serial.

  • batching (bool, default False) – Whether to run batch relaxation and MD using torch-sim. Default is False.

Main algorithm for grand canonical evolutionary Monte Carlo (GC-EMC).

Parameters:

  • name (str) – Name of the target system.

  • calculation_dir (str) – Path of the calculation directory.

  • calculation_script (str) – The name of the Python script for calculating the fitness of each configuration. The script must be inside calculation_dir.

  • input_pop (list of ase.Atoms objects) – Input population for the EMC run.

  • fix_indices (list of ints, default None) – A list of atom indices that should be immutable and fixed in positions throughout the EMC run. Nothing is fixed by default.

  • trim_generation (int, default 100) – To trim database (with backup) every N steps. The database file would be too large and adding new data would be too slow without trimming.

  • md_generation (int, default 10) – To perform molecular dynamics every N steps.

  • mu_walk_generation (int, default 1) – To perform mu-walk operation every N steps.

  • exchange_generation (int, defatul 1) – To perform replica exchange every N steps.

  • bias_starting_step (int, default None) – From which step should a bias weight be considered in the mu-walk operations to uniformly sample the chemical potential space. The bias weight used here is the dimensionless free energy estimated by MBAR. Chemical potential space is not sampled uniformly if this is not set.

  • mbar_starting_step (int, default 100) – From which step should MBAR starts sampling data for estimating free energy differences to uniformly sample the chemical potential space.

  • mbar_sample_stride (int, default 10) – The number of steps that separates two samples at each state for MBAR free energy difference calculations to uniformly sample the chemical potential space.

  • crossover_rate (float, default 0.) – The rate of performing crossover operations.

  • interswap_rate (float, default 0.) – The rate of performing interswap operations.

  • slab_intraswap_rate (float, default 0.) – The rate of performing intraswap operations in the catalyst slab.

  • slab_mutation_rate (float, default 0.) – The rate of performing intraswap operations in the catalyst slab.

  • adsorbate_insertion_rate (float, default 0.) – The rate of adding an adsorbate fragment to the catalyst surface.

  • adsorbate_removal_rate (float, default 0.) – The rate of removing an adsorbate fragment from the catalyst surface.

  • adsorbate_displacement_rate (float, default 0.) – The rate of moving an adsorbate fragment from one adsorption site to another on the catalyst surface.

  • adsorbate_mutation_rate (float, default 0.) – The rate of mutating the type of an adsorbate fragment to another type.

  • adsorbate_surface_dmax (float, default 2.5) – The distance to the catalyst surface (in Å) that a fragment should still be considered as an adsorbate. Fragments that are further away more than this value from the catalyst surface will be removed from the simulation cell automatically.

  • adsorbate_adsorbate_dmin (float, default 2.) – The minimum adsorbate-adsorbate distance (in Å) that allowed during the EMC run. Effectively setting a maximum coverage while avoid overlapping.

  • max_adsorbate_species (int, default None) – The maximum number of unique adsorbate fragment types allowed in a single simulation cell during the EMC run. No such restriction if this is not set.

  • max_adsorbate_coverage (float, default 1.) – The maximum adsorbate coverage (in ML) allowed in a single simulation cell during the EMC run.

  • metal_element_pool (list of strs, default None) – The list of target metal elements (including ‘X’ which represents vacancy) that should be mutable during the EMC run.

  • nonmetal_element_pool (list of strs, default None) – The list of target non-metal elements (including ‘X’ which represents vacancy) that should be mutable during the EMC run.

  • bulk_metal_composition (dict of (str, float) pairs, default None) – The reference metal composition of the bulk catalyst system.

  • adsorbate_species (list of strs, default None) – The list of adsorbate fragment types used to perform adsorbate operations. The internal partition function values for such species must be provided in temperature_species_internal_map.

  • other_adsorbate_species (list of strs, default None) – The list of adsorbate fragment types that are not involved in adsorbate operations but is still allowed during the EMC simulation. The internal partition function parameters for such species must be provided in temperature_species_internal_map.

  • mutable_metal_indices (list of ints, default None) – The list of metal atom (or ‘X’ which represents vacancy) indices that are allowed to mutate during the EMC run. Default None means all metal indices are mutable.

  • mutable_nonmetal_indices (list of ints, default None) – The list of non-metal (or ‘X’ which represents vacancy) indices that are allowed to mutate during the EMC run. Default None means all non-metal indices are mutable.

  • slab_indices (list of ints, default None) – The list of atom indices that corresponds to the catalyst slab. Note that these atom indices will be preserved throughout the EMC run.

  • volume (float, default None) – The accessible volume for the simlated grand canonical system. Note that the metal-atom-occupied space should be subtracted from the volume calculation.

  • reaction_conditions (numpy.ndarray, default None) – The chemical potential and temperature array that represents the reaction condition grid to explore. Each row represents a unique reaction condition, and temperatures must be included in the last column.

  • element_column_map (dict of (str, int) pairs, default None) – A dictionary that maps each non-metal element to the column index that corresponds to the chemical potential of the element.

  • element_eref_map (dict of (str, float) pairs, default None) – A dictionary that maps each non-metal element to the reference total energy of the element. This is only useful if the provided reaction_conditions include relative chemical potentials. No need to set this if only absolute chemical potentials are included, since zero reference energies are set by default. Only needed if the free energy bias weight is applied.

  • element_y2x_map (dict of (str, float) pairs, default None) – A dictionary that maps each non-metal element to the reference bulk relative stoichiometry to the metal in a M_x{NM_y} compound. E.g. for a MnFeCO3 bulk compound should be set as {‘C’: 1/2, ‘O’: 3/2}. No need to set this if the system only has metal atoms, since y2x values are set to zero by default. Only needed if the free energy bias weight is applied.

  • temperature_dmu_map (dict of (float, float) pairs, default None) – A dictionary that maps each temperature to the estimated the chemical potential difference between all metal pairs (e.g. obtained from bulk GE-EMC simulations). Note that the keys must be in the form of ‘A2B’ which represents mu_B - mu_A, must consider all possible metal pairs, and the metal element order must follow the order in the metal_element_pool. Only needed if the free energy bias weight is applied. Default is None, which is only suitable for surface EMC simulations with fixed surface metal composition.

  • temperature_species_internal_map (dict of (float, dict) pairs, default None) – A dictionary that maps the temperature to the dictionary of adsorbate fragments’ internal partition function values.

  • adsorption_sites (acat.SlabAdsorptionSites object, default None) – Fallback option when the AutoAdsorbate adsorption sites identification failed in the first step. In most cases not needed.

  • ignore_sites (str or list of strs, default None) – The catalyst surface adsorption sites that should not be considered for adsorbate insertion. Common practice is to ignore ‘bridge’ sites to accelerate the EMC run.

  • raw_score_cutoff (float, default -10000.) – The fitness score for candidates that are should not be considered in the sampling. This could be structures that are unphysical / failed to relax by the calculator.

  • temperature_key (str, default 'temperature') – Keyword for the temperature stored in each configuration.

  • replica_key (str, default 'replica') – Keyword for the replica number stored in each configuration.

  • acceptance_key (str, default 'accepted') – Keyword for indicating being accepted or not in each configuration

  • gpu_devices (list of ints, default None) – The list of GPU devices to use. Default is to use a single GPU/CPU device.

  • procs_per_device (int, default 1) – The number of processes to run in parallel on each GPU/CPU device. Defaul is to run in serial.

  • batching (bool, default False) – Whether to run batch relaxation and MD using torch-sim. Default is False.

catemc.repulsive module¶

class catemc.repulsive.RepulsivePotential(restart=None, ignore_bad_restart_file=<object object>, label=None, atoms=None, directory='.', **kwargs)[source]¶

Bases: Calculator

Repulsive potential defined as sum_ij U(xij), defining xij = rij / [rc*(Ri + Rj)] where Ri and Rj are the radii of atom i an j, rij is their distance and rc a scaling constant, the potential U can take two forms:

parabola form (goes to constant/prefactor at rij=0)

U = prefactor * (xij-1)**exponent if rij<=xij U = 0 else

Lennard jones like repulsive form (goes to infinity at rij=0)

U = prefactor * [1/(xij**exponent)-1] - exponent*(1-xij)] if rij<=xij U = 0 else

Examples

>>> potential=RepulsivePotential(prefactor=..., rc=...)
>>> to calculate, use as any ASE calculator,
e.g. potential.get_potential_energy()
Parameters:

  • prefactor (float, optional) – Strength constant for potentals Default is 1

  • rc (float, optional) – Multplier on sum of atomic radii Default is 0.9 (can also be imported as a list giving the radius of each atom)

  • potential_type (str ('parabola' or 'LJ'), optional) – String specifying what mode of the potential is used. Default is ‘LJ’

  • exponent (float, optional) – Exponent used in potentials Default is 2

  • extrapotentals (list of objects, optional) – List of additional objects capable of calculating, energy, forces and stresses. Any objects with the following methods: potential(atoms), forces(atoms), stress(atoms) default: None (no extra potential used)
