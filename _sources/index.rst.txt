CatEMC Documentation
====================

**CatEMC** is a Python package for running evolutionary Monte Carlo (EMC)
simulations for complex bulk and surface heterogeneous catalyst materials.
This documentation is organized into four main sections so you can quickly
find the workflow stage you need:

* Initial replica generation (bulk & surface)
* EMC simulations (canonical, Gibbs, grand-canonical)
* MBAR analysis (Δμ estimation and structural averages)
* Visualization (surface phase diagrams)

API reference
=============

The API reference is autogenerated from the package docstrings.
To regenerate API pages run::

   sphinx-apidoc -o docs/source/ catemc

Then build the docs with::

   cd docs
   make html
