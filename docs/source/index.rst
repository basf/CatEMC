CatEMC
======


**CatEMC** is a Python package for running evolutionary Monte Carlo (EMC) simulations for complex bulk/surface heterogeneous catalyst materials. The package provides tools to:


- generate populations of structures and μ-windows,
- run Gibbs-ensemble EMC (GE-EMC) bulk simulations at different temperatures,
- run extended grand-canonical EMC (GC-EMC) surface simulations at different temperatures and reaction conditions,
- analyze GE-EMC/GC-EMC outputs to estimate metal chemical potential differences and structural expectations,
- visualize free-energy surfaces and phase diagrams.
